# Reactor 1.3.0 — Make your move

- Learn by playing: ten guided scenarios teach placing atoms, growing a cell, corner/edge/centre bursts, capture, winning chains, teammate ownership, free-for-all elimination and timed moves. First-time players can skip the offer; everyone can replay the guide from How to Play. Tutorial progress never replaces a saved match.
- Four online formats: 1v1, 2v2 teams, three-player and four-player free-for-all. Each has its own points, seven ranks, protection meter, lifetime peaks and dynamic top-100 Singularity leaderboard. Existing 1v1 progress carries forward.
- Invite exact usernames into a friendly room, accept invitations, and start once every seat is ready. Team seats are fixed: players 1/3 versus 2/4. Allies can place in each other's cells and share a victory. Friendly rooms do not award ranked points.
- Total time banks: **Spark 1+1**, **Surge 3+0 / 3+1**, **Orbit 10+0 / 10+1**. Every increment option adds exactly one second after an accepted move. Ranked searches only match the same format and clock, within the existing bounded skill gap.
- Online time belongs to the server and keeps running while the app is away. Running out of time eliminates that seat; remaining players continue where appropriate. Move retries cannot charge twice or add another increment. A forfeited teammate cannot collect a win.
- Offline Solo offers the same clocks or Untimed. Clocks pause for local pauses, menus and reactions, and save with the match. Existing saves without clocks stay untimed. The next solo game defaults to Orbit 10+1.
- Compact player clocks and team labels, responsive four-player cards, vibrant room controls and steady lobby animations. Real CC0 sounds and the hidden reaction length remain intact.

Accounts, friends, earned achievements, username changes, password recovery and encrypted sessions carry forward. Email verification is off during this beta. Seasons remain inactive: **Seasons coming soon**.

Android: version 1.3.0, code 8, package `com.reactorstudio.chainarena`, same signing identity and HTTPS update route. Download through the public GitHub release or Personal Projects site; Android requires installation approval. No ADB installation is part of this release.

Windows: the installed classic copy and private native backups are updated. The unsigned installer stays private while the separate Microsoft Store process continues. **Google Play publication remains paused** until the owner approves the beta. The offline browser edition has its own version and interface.

Validation covers deterministic rules, real PostgreSQL authorization/ranking/room/clock checks, native portrait and desktop UI, offline clock expiry/save restoration, all ten playable lessons, and four native clients completing every ranked format plus a friendly team room. Temporary QA users are isolated from public queues and leaderboards. This release is not claimed as a physical-phone installation or device test.

Sound assets: Kenney Interface Sounds and Digital Audio, both CC0. Original licences and credits remain in the project.
