# Reactor 1.1.2

- Fixed silent native sound playback. Placements, hops, landings, reactions and wins now reach the game's audio output.
- Kept the six real Kenney CC0 clips, restrained levels, overlap limit, mute, volume and preview controls.
- Removed the live wave count and total chain length. Each reaction unfolds without revealing how many waves remain; completed match statistics are retained.
- Preserved saved games, settings, phone vibration, app identity and the Android update signing lineage.
- Connected native builds to the public update feed. The original 1.1.0 phone test build needs this one upgrade before future releases can be offered inside Reactor. Android asks for installation approval.

Sounds: [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds) and [Kenney Digital Audio](https://kenney.nl/assets/digital-audio), both CC0. Original licences are retained in this distribution repository; clip provenance is included in the private source repository.

The browser edition is independently versioned. Public Windows distribution awaits publisher signing or explicit approval of an unsigned test installer.
