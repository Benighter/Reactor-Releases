# Third-party sound assets

Reactor's six native sound effects are unmodified assets from two Kenney CC0 packs:

| Effect | Original file | Pack |
| --- | --- | --- |
| Placement | pluck_001.ogg | Interface Sounds |
| Hop | phaseJump1.ogg | Digital Audio |
| Landing | drop_002.ogg | Interface Sounds |
| Burst | pepSound2.ogg | Digital Audio |
| Interface | click_003.ogg | Interface Sounds |
| Victory | powerUp3.ogg | Digital Audio |

Pack pages: [Interface Sounds](https://kenney.nl/assets/interface-sounds), [Digital Audio](https://kenney.nl/assets/digital-audio).

The original pack license files are retained in `licenses`. This CC0 dedication applies to those third-party sounds, not to Reactor's game code or branding.
