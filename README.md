# Reactor

**Small moves. Explosive chains.** A chain-reaction strategy game made by Bennet.

Play solo against Reactor AI, share one screen with 2–4 players, or solve a one-move takeover in Chain Lab.

## Download

- [Android 1.1.2 APK](https://github.com/Benighter/Reactor-Releases/releases/download/v1.1.2/Reactor-1.1.2.apk)
- [Latest release and notes](https://github.com/Benighter/Reactor-Releases/releases/latest)
- [Benighter Personal Projects](https://benighters-personal-projects.vercel.app/releases/reactor/)

Android 8.0 or newer and an ARM64 device are required. This is a direct test release, distributed outside Google Play. Android may ask you to allow installation from your browser. Future releases can be offered inside **Settings → More → Updates**, with Android approval required to install them.

The Windows version is available locally to its owner; a public Windows download awaits publisher signing or approval of an unsigned test release.

## Version 1.1.2

- Fixed sound playback for placements, hops, landings, reactions, and wins.
- Real Kenney CC0 clips, with volume, mute, and a sound preview.
- Chains unfold without revealing their remaining length.
- Animated settings, compact menus and victory recaps, help, and three themes.
- Saved games carry forward during an in-place update.
